How I work on production issues

A structured, repeatable approach to debugging and incident management.

  • Clarify the impact. Start with what’s broken, who is affected, and how urgent it is.
  • Gather evidence. Logs, metrics, traces, dashboards, and recent changes — build a clear picture before guessing.
  • Form and test hypotheses. Narrow down likely causes, test them quickly, and adjust based on what the data shows.
  • Communicate clearly. Keep stakeholders updated with concise, factual summaries — no noise, no drama.
  • Document and follow through. Capture what happened, why, and what will prevent it next time.

API Debugging Walkthrough — Failed Payment Request

A Circle‑style investigation into intermittent API failures.

Scenario: A payment API endpoint intermittently fails for certain merchants.

Impact: ~2% of transactions fail during peak hours.

Investigation steps:

  • Filtered API logs by endpoint and error codes.
  • Compared successful vs failed payloads.
  • Checked observability dashboards for latency spikes.
  • Reproduced the issue using Postman.

Root cause: A merchant‑generated payment_reference format was rejected by the validation service, causing upstream failures.

Outcome: Validation rules updated, error propagation improved, and monitoring enhanced.

On‑Chain Investigation — Failed Ethereum Transaction

A structured analysis of a reverted DeFi swap.

Scenario: A user reports a failed Uniswap swap that still consumed gas.

Investigation steps:

  • Loaded the transaction hash on Etherscan.
  • Decoded input data to inspect swap parameters.
  • Checked pool liquidity and price movement at the block.
  • Compared expected vs actual output amounts.

Root cause: Slippage exceeded due to rapid price movement.

Outcome: User educated on slippage, retry guidance provided, and scenario added to troubleshooting notes.

End‑to‑End Trace — API Request to Blockchain Transaction

Explaining how API actions become on‑chain events.

Scenario: A user initiates a crypto transfer via an API endpoint.

Flow:

  • API request received and validated.
  • Backend checks balances and constructs transaction.
  • Transaction signed via secure key management.
  • Broadcast to the blockchain network.
  • Transaction enters mempool.
  • Included in a block and confirmed.

Outcome: Clear understanding of how API and blockchain layers interact.
